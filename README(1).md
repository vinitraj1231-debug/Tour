# FF Arena Website

This is a responsive multi-page website recreated from the supplied FF Arena reference images.

## Pages
- `index.html` — Home / official APK landing page
- `leaderboard.html` — Live leaderboard
- `about.html` — About FF Arena
- `features.html` — Features
- `support.html` — Support Center

## Navigation change requested
The first screenshot originally had `APP` in the header. It has been changed to `HOME` and the full navigation is:
HOME · LEADERBOARD · ABOUT · FEATURES · SUPPORT

## APK
Put your real APK file at:

`assets/ff-arena.apk`

All Download APK buttons already point there.

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

Example:
```bash
python -m http.server 8080
```

Then open:
`http://localhost:8080/`
